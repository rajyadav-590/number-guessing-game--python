# Number Guessing Game (Python)

## 📌 Project Description

This is a simple Python-based Number Guessing Game.
The computer randomly selects a number, and the player has to guess it.
After each guess, the program gives hints like:

* Too High
* Too Low
  The game continues until 10 attempts

This project is beginner-friendly and helps in understanding Python basics like loops, conditions, error handling and user input.

---

## 🎯 Features

* Random number generation
* User input handling
* Hint system (High / Low)
* Counts number of attempts
* Simple and interactive gameplay
* error handling
* limited attempts upto 10

---

## 🛠️ Technologies Used

* Python 3
* Random module
* error handling

---

## ▶️ How to Run the Program

1. Install Python (if not installed)

   * Download from: https://www.python.org/

2. Save the program file
   Example: `number_guessing.py`

3. Open terminal or command prompt

4. Run the program:

```
python number_guessing.py
```
